# Blog Thumbnail Prompts — All Posts

One ready-to-paste image-generation prompt per blog post, pre-filled with the
title and a tailored diagram motif. All prompts share the same
**developeruche** "light terminal / blueprint" design system (see
`assets/BLOG_THUMBNAIL.prompt.md` for the canonical template and palette).

**Workflow:** copy a post's prompt block → generate at **1600×900 (16:9)** →
save to the listed `assets/blog/<slug>.png` path → set that post's `thumbnail`
field in `data/blog.json`.

**Shared style preamble** (already embedded in every block below):
warm off-white paper `#F4F2EC` with a faint navy engineering grid, dark-navy ink
`#0B1A2E`, single accent navy `#1B3A6B`, muted navy-gray `#54627A`; flat 2D
blueprint/terminal vector look; all-caps pixel/monospace lettering; `//` label +
`→` accent; thin navy line-art diagram in the background, title as focal point;
no neon/3D/photo/people/logos; AA contrast; spell the title exactly.

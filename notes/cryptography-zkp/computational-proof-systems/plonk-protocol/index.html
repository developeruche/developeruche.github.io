The PLONK Protocol

// Developer Uche · 2026-11-06

This part of the book aims to explain every component of the PLONK protocol, clarify the mathematics involved and untangle the complicated concepts. It is structured for readers who are just meeting PLONK as well as OGs.

Contents

  2. Plonkish Arithmetization
  3. The PLONK Prover

Completing these chapters should give you a good understanding of the PLONK protocol. The Rust code implementing it is here: arks/snarks/plonk.
